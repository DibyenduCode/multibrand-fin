# multibrand-fin

Multi-Brand Corporate Treasury & Financial Operations Management System built with PHP and Tailwind CSS.

## Features
- **Multi-Brand Management**: Manage finances, cash flow, income, and expenses across multiple brands.
- **Bank Account Balance Tracking**: Real-time liquid cash reserve tracking across active bank accounts.
- **Fixed Monthly Expense Reminders**: Automated recurring expense tracking with configurable Super Admin lead-time notification bell alerts.
- **Inter-Brand Loans & Repayments**: Complete tracking of internal borrowings, lender/borrower records, and repayment ledgers.
- **Role-Based Access Control**: Super Admin, Brand User, and Read-Only Manager accounts.
- **SweetAlert2 Theme Integration**: Modern UI popups and flash toasts.
